# oneM2M 양방향 보안 게이트웨이

Mobius4 기반 **oneM2M 양방향 보안 게이트웨이와 장치별 실행 전 안전 정책 서비스** 제안 작업 저장소입니다.

> 이 저장소의 일정·예산·가격·성능 수치는 검증 완료 성과가 아니라 개발 계획 또는 사업 가정입니다. 제안은 모든 공격 차단이나 물리적 안전을 보장한다고 주장하지 않습니다.

## 핵심 제안

- IoT → 서버: 요청량, 자원 범위, 데이터 형식·신선도·신뢰 상태를 검사
- 서버 → IoT: 인증·ACP를 통과한 뒤 장치 상태·명령 순서·근거 데이터·만료를 실행 전에 재확인
- 네트워크: 허브를 통과하는 경로에 구간 분리와 Suricata IPS 연계
- 운영: 정책 버전, 판단 근거, 실행 결과, 차단 사유와 복구 이력을 연결
- 실증: 도어락·난방 저전압 모형으로 센서 오염 → 서버 판단 → 위험 제어 제한 흐름을 재현

## 기준과 범위

- Mobius4 기준: v4.24.5, commit `3da4d8523694b5077e348ab1c9e769fb3a30df24`
- oneM2M·Suricata·제품·공시·특허 URL은 DOCX 부록 및 PPT 발표자 노트에 기록
- 선행특허 조사는 전수조사·특허성 판단·실시자유(FTO) 의견이 아님

- 실제 장치 연동은 제조사 API·현장 인터록·인증 조건을 별도로 확인
